# Art Hackers

Art Hackers is an independent open-source organization focused on security research, offensive security tooling, developer infrastructure, and cross-platform software development.

We build practical software for developers, security professionals, researchers, and enthusiasts who value simplicity, reliability, and performance.

---

## Mission

Our mission is to create high-quality open-source software that empowers developers and security practitioners to build, test, automate, and innovate with confidence.

We believe that great software should be:

* Accessible
* Well documented
* Cross-platform
* Easy to adopt
* Open and community-driven

---

## Areas of Focus

### Offensive Security

Research and development of tools, techniques, and workflows that assist security professionals in understanding, evaluating, and improving defensive security posture.

### Software Development

Designing libraries, frameworks, and tooling that simplify application development across desktop and mobile platforms.

### Developer Infrastructure

Creating utilities, automation tools, SDKs, and supporting technologies that improve the developer experience.

### Open Source Research

Exploring new ideas in programming languages, software architecture, GUI frameworks, and modern development workflows.

---

## Featured Projects

### Artemis

Artemis is a cross-platform GUI framework for Python designed to simplify application development for desktop and mobile environments.

Key objectives include:

* Unified development experience
* Clean and intuitive APIs
* Cross-platform compatibility
* Modern application architecture
* Efficient deployment workflows
